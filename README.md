## 🚀 Selected Work

Most of this is client work in private repositories, so here's what I built rather than links to code.

| Project | What it does | Stack |
| --- | --- | --- |
| **[HireIQ](https://github.com/hdwije/hireiq)** | RAG-based HR assistant. Upload CVs, JDs and policies, ask questions, get answers grounded in the documents | Turborepo, NestJS, Next.js, PostgreSQL + pgvector, BullMQ |
| **Itinerary Generation System** | Travel planning platform for Sri Lanka and Maldives. Dynamic destination, hotel and transport builder, live cost calculation, Google Maps routing, PDF/Word export, role-based access. Cut itinerary creation time by ~70% | NestJS, Next.js, PostgreSQL, Auth0, AWS SES, Puppeteer, Playwright |
| **SMS Management System** | Batch messaging platform for an insurance client handling 300,000 recipients per run. Template approval workflows, recipient lists, delivery logs. Dispatch time went from days to under 2 hours | NestJS, Next.js App Router, Tailwind, HeroUI, Twilio, JWT |
| **Cipher** | AI sentiment analysis over 40M+ product reviews for global apparel brands. Batching and retry logic around GPT rate limits, SQS fault-tolerant queues, full pipeline observability. Cut manual review effort by ~90% | NestJS, Next.js, OpenAI API, AWS CDK, SQS, Lambda, Cognito, CloudWatch, New Relic |
| **Healthcare Rostering (UK)** | Workforce scheduling for UK care providers. Web app for schedulers, mobile app for carers, real-time booking visibility for service users. Replaced paper workflows, improved shift allocation efficiency by ~60% | NestJS, Next.js, React Native, Socket.IO, RabbitMQ, MySQL, AWS Cognito, Step Functions |
| **EdTech Platform** | Core services for an online learning product covering 6 international curricula. Refactored CDK and Serverless pipelines, improved response times by ~25%. Event-driven SQS pipelines cut data pipeline failures by ~50% | NestJS, Next.js, MongoDB, Serverless Framework, AWS CDK |

I also led a 5-engineer Agile team, ran code reviews and technical interviews, and introduced automated quality gates that reduced post-release bugs by ~40%.
